# soruindir.net

- `eklenti/onlinesorucoz.php` — WordPress eklentisi (online testler, öğretmen/öğrenci panelleri, Soru Havuzu, Yazılı Hazırla). Sitede *Eklentiler* klasöründeki dosyanın yerine yüklenir.
- `tema/` — temaya ait `header.php` ve `front-page.php`.
- `sablon/soru-havuzu-sablonu.docx` — Soru Havuzu'na Word'den toplu soru eklemek için yazım şablonu.
- `kaynak/` — eklentinin parçaları ve derleme betiği (`build.sh`); `onlinesorucoz.php` bu parçalardan üretilir.
